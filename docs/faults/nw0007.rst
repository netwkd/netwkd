NW0007. A peer sent a packet that could not be used
===================================================

Reported as a warning the first time a peer sends a packet this peer cannot
use. The rest from that peer are counted, and the session end summary adds
how many.

The packet was dropped. This happens when two peers run different Networked
versions, when a packet is cut short or arrives damaged, and when a packet
arrives that this peer was not waiting for.

Run the same Networked version on every peer.
