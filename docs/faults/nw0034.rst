NW0034. Something was declared twice
====================================

Reported as an error when a ``configure_*`` call declares a thing that is
already declared on the same node, or a database, schema, transport or saved
column is declared a second time.

The second declaration was refused. The log line names the declaration and
where it was declared.

.. code-block:: gdscript

    func _init() -> void:
        Netw.configure_session(self)
        Netw.configure_session(self)

Declare it once, and keep what the first call returned.

.. code-block:: gdscript

    func _init() -> void:
        var config := Netw.configure_session(self)
        config.bandwidth_kbps = 512
