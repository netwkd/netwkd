NW0034. Something was declared twice with different values
==========================================================

Reported as an error when a ``configure_*`` call declares a thing that is
already declared on the same node with different values.

The second declaration was refused. The log line names the declaration and
the node.

.. code-block:: gdscript

    func _init() -> void:
        Netw.configure_property(self, &"health").state()
        Netw.configure_property(self, &"health").broadcast()

Declare it once, and keep what the first call returned.

.. code-block:: gdscript

    func _init() -> void:
        var health := Netw.configure_property(self, &"health")
        health.state()
