NW1007. A handler returned the wrong kind of value
==================================================

Reported as an error when a handler you declared returns nothing, or a value
of another type than netwkd asks for.

The result was ignored. The log line names the handler, what it returned and
what to return.

.. code-block:: gdscript

    func fetch(nonce: String) -> String:
        return saved_token

Return what the log line asks for, such as a ``NetwPromise``.

.. code-block:: gdscript

    func fetch(nonce: String) -> NetwPromise:
        return account_service.request_token(nonce)
