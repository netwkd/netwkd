NW0031. A call got an empty argument
====================================

Reported as an error when a call that needs a name, node or object is given
an empty one.

The call did nothing. The log line names the call and the argument.

.. code-block:: gdscript

    Netw.prepare_join(self, "")

Pass a value for the argument.

.. code-block:: gdscript

    Netw.prepare_join(self, "Ana")
