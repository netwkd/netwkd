NW0008. Two clients connected with the same peer id
===================================================

Reported as a warning when a client connects as a peer id that another peer
already holds.

The new connection was refused.

The fix is to call :ref:`NetwConnection.join <class_NetwConnection_method_join>`
again on that client, which picks a new peer id with
:godot:`ENetMultiplayerPeer`.
