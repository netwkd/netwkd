NW0009. Networked ran its steps in the wrong order
==================================================

Reported as an error when Networked finds a state its own code should have
prevented. This is a bug in Networked and not in your game.

The log line names the place where Networked stopped.

.. code-block:: text

    Networked stopped at <place> because of a bug in Networked, not in this
    game. Report it to Networked with this log. [NW0009]

Report it with the full log and the steps that led to it.
