NW0009. netwkd ran its steps in the wrong order
==================================================

Reported as an error when netwkd finds a state its own code should have
prevented. This is a bug in netwkd and not in your game.

The log line names the place where netwkd stopped.

.. code-block:: text

    netwkd stopped at <place> because of a bug in netwkd, not in this
    game. Report it to netwkd with this log. [NW0009]

Report it with the full log and the steps that led to it.
