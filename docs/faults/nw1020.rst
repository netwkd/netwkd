NW1020. A call is not supported for this case
=============================================

Reported as an error when a call is made for a case Networked does not
support. The cases are a synchronizer that stopped, a node outside the
spawnable scenes, an entity moved to another viewport, a scene change that
freed the session, a read only schema, a scene's own interest layer, a config
passed to ``object_configuration_add``, a directory with no friends list, a
transport that moves the server under link conditions, an interpolator
on a value inside a resource, such as ``stats:health``, and a property
that holds an Object declared with ``Netw.configure_property``.

The call was ignored. The log line names the call and the case.

Use what the log line asks for. To change an interest layer that belongs to a
multiplayer scene, change it through the
:ref:`NetwScene <class_NetwScene>` that :ref:`Netw.scene <class_Netw_method_scene>`
returns.
