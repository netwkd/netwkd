NW0010. Handlers kept giving the session more work
==================================================

Reported as a warning when handlers the session called are still giving
it more work after the last pass it allows in one update. The rest runs
on its next update, so nothing is lost. It is reported once per session.

A :ref:`NetwEntity.despawned <class_NetwEntity_signal_despawned>`
handler that frees the next node of a chain hands the session one more
node each pass, so a long chain takes several updates to finish.

.. code-block:: gdscript

    func _on_despawned() -> void:
        next_link.free()

Free the next node with ``queue_free()``, or defer other work with
``call_deferred()``, so it runs at the end of the frame.

.. code-block:: gdscript

    func _on_despawned() -> void:
        next_link.queue_free()

Any handler the session calls can keep it busy the same way, such as
a :ref:`NetwEntity.reparented <class_NetwEntity_signal_reparented>`
handler that moves the next entity, or a
:ref:`Netw.request_all <class_Netw_method_request_all>` callback that
calls ``request_all`` again.
