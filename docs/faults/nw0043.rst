NW0043. A setting cannot be used with another setting
=====================================================

Reported as an error when a setting is declared next to one it cannot work
with. This covers ``TRANSFER_IMMEDIATE`` set on an entity that is already in
the tree and holds server authority, ``retained`` on predicted state, a
variable size column in a replicated schema, and a callback with a policy
other than the custom one.

It also covers a property declared with two of ``state``, ``input`` and
``broadcast``, which is left out, and these settings.

- ``unchecked``, ``extrapolate``, ``teleport_only`` and the
  correction settings on an ``input`` or a ``broadcast`` property
- ``windowed`` and ``audience`` on a ``broadcast`` property
- ``extrapolate`` naming a property that is not ``state`` on the same node
- a policy, ``reliable``, ``unreliable``, ``call_local``, ``call_remote``,
  ``interpolate`` or ``defer_until`` on a spawn function
- ``defer_until`` on a signal or a property

The setting was refused. The log line names it, the setting it conflicts with
and what to use.

.. code-block:: gdscript

    func _init() -> void:
        Netw.configure_entity(self).authority = NetwEntity.AUTHORITY_SERVER

    func _ready() -> void:
        NetwEntity.of(self).transfer = NetwEntity.TRANSFER_IMMEDIATE

Use what the log line asks for. For ``TRANSFER_IMMEDIATE``, set the authority
to ``NetwEntity.AUTHORITY_CONTROLLER`` before the node enters the tree.

.. code-block:: gdscript

    func _init() -> void:
        var entity := Netw.configure_entity(self)
        entity.authority = NetwEntity.AUTHORITY_CONTROLLER
        entity.transfer = NetwEntity.TRANSFER_IMMEDIATE
