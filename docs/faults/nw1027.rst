NW1027. A part and its entity set one option differently
========================================================

Reported as a warning when a node that a scene places under an entity sets
an option through
:ref:`Netw.configure_entity <class_Netw_method_configure_entity>`, and the
entity above it already set the same option to another value.

The entity keeps its own value. The log line names both nodes and the
option.

``Wheel`` is a plain child in ``car.tscn``, under ``Car``.

.. code-block:: gdscript

    # car.gd
    func _init() -> void:
        Netw.configure_entity(self).authority = NetwEntity.AUTHORITY_SERVER

    # wheel.gd
    func _init() -> void:
        Netw.configure_entity(self).authority = NetwEntity.AUTHORITY_CONTROLLER

Set the option in one place.

.. code-block:: gdscript

    # car.gd
    func _init() -> void:
        Netw.configure_entity(self).authority = NetwEntity.AUTHORITY_CONTROLLER
