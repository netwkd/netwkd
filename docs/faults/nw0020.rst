NW0020. The admission handler refused the host
==============================================

Reported as an error when the host asks to join its own session and the
handler declared with ``Netw.configure_admission`` refuses it.

The host has no :ref:`NetwPlayer <class_NetwPlayer>`. The log line gives the
refusal.

.. code-block:: gdscript

    func admit(request: NetwJoinRequest) -> void:
        if invited.has(request.peer_id):
            request.admit()
        else:
            request.deny()

Admit peer 1 in the handler.

.. code-block:: gdscript

    func admit(request: NetwJoinRequest) -> void:
        if request.peer_id == 1 or invited.has(request.peer_id):
            request.admit()
        else:
            request.deny()
