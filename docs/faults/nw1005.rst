NW1005. A call got a Callable it cannot call
============================================

Reported as an error when a call is given a Callable that is invalid, freed
or bound to an object that no longer exists.

The Callable was ignored. The log line names the call and what to pass.

.. code-block:: gdscript

    Netw.configure_rpc(Callable())

Pass a Callable of a method that exists on a live node.

.. code-block:: gdscript

    Netw.configure_rpc(self.apply_stun)
