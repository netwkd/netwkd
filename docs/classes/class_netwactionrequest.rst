NetwActionRequest
=================

**Inherits:** :ref:`NetwRequest<class_NetwRequest>` **<** :godot:`RefCounted`

Information about a :ref:`Netw.action()<class_Netw_method_action>` request, passed to its method on the server.

.. rst-class:: classref-introduction-group

Description
-----------

A :ref:`NetwRequest<class_NetwRequest>` that is the first argument, before the arguments of :ref:`Netw.action()<class_Netw_method_action>`. Call :ref:`bind()<class_NetwActionRequest_method_bind>` on a node the action spawns, before adding it to the tree. Call :ref:`NetwRequest.deny()<class_NetwRequest_method_deny>` to reject the action. The requesting peer undoes its prediction, and its :ref:`NetwActionConfig.revert()<class_NetwActionConfig_method_revert>` handler receives the code and the reason, which is cut to 255 UTF-8 bytes.

::

    func place_bomb(request: NetwActionRequest, pos: Vector2) -> void:
        var past := Netw.sample(entity, request.view_tick)
        if not past.has_value(&"position"):
            request.deny("no position at that tick")
            return
        var bomb := BOMB.instantiate()
        request.bind(bomb)
        bombs.add_child(bomb)
