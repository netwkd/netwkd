NetwTestGame
============

**Inherits:** :godot:`Node`

A server and its clients for one game, running in one process for a test.

.. rst-class:: classref-introduction-group

Description
-----------

Each peer runs its own instance of the game's :godot:`PackedScene`. Only one game runs at a time. :ref:`run()<class_NetwTestGame_method_run>` and :ref:`until()<class_NetwTestGame_method_until>` count ticks, and nothing in the game counts seconds. Freeing the game is the whole teardown.

::

    var game := NetwTestGame.new(MAIN)
    game.failed.connect(fail)
    add_child(game)

    var ada := await game.host(&"ada")
    var bob := await game.join(&"bob")
    var seen: Node2D = await game.until(ada.player.bind(&"bob"))
    bob.press(&"move_right")
    await game.run(12)

    game.free()

\ A test hosts or serves once, joins its clients, and reads what each :ref:`NetwTestPeer<class_NetwTestPeer>` sees through :ref:`NetwTestPeer.session<class_NetwTestPeer_property_session>`.
