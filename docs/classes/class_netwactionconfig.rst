NetwActionConfig
================

**Inherits:** :godot:`RefCounted`

How one action a node declared is predicted, and when the server runs it.

.. rst-class:: classref-introduction-group

Description
-----------

Every peer declares the action in ``_init`` on the root node of a :ref:`NetwEntity<class_NetwEntity>`, and each node keeps its own settings.

::

    func _init() -> void:
        Netw.configure_action(place_bomb) \
                .predict(ghost_bomb) \
                .timing(NetwActionConfig.TIMING_TICK_ALIGNED_STATE_READY)

.. _class_NetwActionConfig_method_revert:

.. rst-class:: classref-method

:ref:`NetwActionConfig<class_NetwActionConfig>` **revert**\ (\ handler\: :godot:`Callable`\ ) :ref:`🔗<class_NetwActionConfig_method_revert>`

Sets the method that runs on the peer that asked once the server denied the action or did not answer in time. It receives the :godot:`Node` the :ref:`predict()<class_NetwActionConfig_method_predict>` handler returned, or ``null``, with the code and the reason of :ref:`NetwRequest.deny()<class_NetwRequest_method_deny>`. An action the server did not answer gives :godot:`@GlobalScope.ERR_TIMEOUT <@GlobalScope#class_@GlobalScope_constant_ERR_TIMEOUT>` and an empty reason. With no handler set, that node is freed.
