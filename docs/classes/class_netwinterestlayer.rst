NetwInterestLayer
=================

**Inherits:** :godot:`RefCounted`

A group of entities and the peers that can see them.

.. rst-class:: classref-introduction-group

Description
-----------

The server adds :ref:`entities<class_NetwInterestLayer_property_entities>` and :ref:`viewers<class_NetwInterestLayer_property_viewers>` to a layer, and :ref:`policy<class_NetwInterestLayer_property_policy>` decides which peers see the entities. Two **NetwInterestLayer** objects with the same :ref:`layer_id<class_NetwInterestLayer_property_layer_id>` are the same layer. Clients only learn what they can see.

::

    # server
    var sight := Netw.session(self).interest_layer(&"sight")
    sight.add_entity(target_entity)
    sight.add_viewer(observer_peer_id)

    # client
    var sight := Netw.session(self).interest_layer(&"sight")
    sight.visibility_changed.connect(func(entity: NetwEntity, visible: bool):
        marker_of(entity.root).visible = visible
    )

\ Changes apply at the end of the frame. On the server, use :ref:`interest_entered<class_NetwInterestLayer_signal_interest_entered>` and :ref:`interest_exited<class_NetwInterestLayer_signal_interest_exited>`. On a client, use :ref:`visibility_changed<class_NetwInterestLayer_signal_visibility_changed>`.

An entity inside a multiplayer scene is only visible to peers in that scene, whatever other layers say.

A :ref:`NetwEntity<class_NetwEntity>` under another entity is only visible to peers that also see the entity above it, whatever its own layers say.

Called on the server once per frame with this layer. It returns every entity that belongs in the layer.

::

    sight.driver = func(layer: NetwInterestLayer) -> Array[NetwEntity]:
        return entities_near(beacon.position, 20.0)

\ If the result holds anything that is not an entity of this session, the layer does not change that frame.
