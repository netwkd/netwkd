NetwRequest
===========

**Inherits:** :godot:`RefCounted`

**Inherited By:** :ref:`NetwActionRequest<class_NetwActionRequest>`, :ref:`NetwControlRequest<class_NetwControlRequest>`, :ref:`NetwJoinRequest<class_NetwJoinRequest>`, :ref:`NetwLifecycleRequest<class_NetwLifecycleRequest>`

Something a peer asked the server for, which the server can deny.

.. rst-class:: classref-introduction-group

Description
-----------

The server hands a game one of :ref:`NetwJoinRequest<class_NetwJoinRequest>`, :ref:`NetwActionRequest<class_NetwActionRequest>`, :ref:`NetwControlRequest<class_NetwControlRequest>` or :ref:`NetwLifecycleRequest<class_NetwLifecycleRequest>`. Each one has the :ref:`peer_id<class_NetwRequest_property_peer_id>` of the peer that asked, and :ref:`deny()<class_NetwRequest_method_deny>` records the :ref:`code<class_NetwRequest_property_code>` and :ref:`reason<class_NetwRequest_property_reason>` the peer that asked receives.

::

    func judge(request: NetwRequest) -> void:
        if banned.has(request.peer_id):
            request.deny("You are banned.", ERR_UNAUTHORIZED)
