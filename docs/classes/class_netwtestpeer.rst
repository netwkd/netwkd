NetwTestPeer
============

**Inherits:** :godot:`RefCounted`

One peer of a :ref:`NetwTestGame<class_NetwTestGame>`, from :ref:`NetwTestGame.serve()<class_NetwTestGame_method_serve>`, :ref:`NetwTestGame.host()<class_NetwTestGame_method_host>` or :ref:`NetwTestGame.join()<class_NetwTestGame_method_join>`.

.. rst-class:: classref-introduction-group

Description
-----------

A test reads what this peer sees through :ref:`session<class_NetwTestPeer_property_session>`, and its input and link changes reach this peer and no other.

::

    var bob := await game.join(&"bob")
    var car: Node3D = await game.until(bob.player)
    bob.impair(NetwLinkConditions.poor_3g())
    bob.press(&"accelerate")
    await game.run(30)
    bob.release(&"accelerate")
    bob.heal()
