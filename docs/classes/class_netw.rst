Description
-----------

**Levels**\ 

A level is spawned like any other node, with :ref:`configure_scene()<class_Netw_method_configure_scene>` in its root. Spawn a player into it with :ref:`spawn_player()<class_Netw_method_spawn_player>` and that player's peer receives the level. :ref:`NetwScene<class_NetwScene>` covers the rest.

::

    # arena.gd
    func _init() -> void:
        Netw.configure_scene(self)

    # game.gd
    func _init() -> void:
        Netw.configure_spawn(make_arena)
        Netw.configure_spawn(make_car)

    func make_arena() -> Node:
        return preload("res://arena.tscn").instantiate()

    func make_car() -> Node:
        return preload("res://car.tscn").instantiate()

    func start_match(lobby: Node) -> void:
        Netw.despawn(lobby)
        var arena: Node = Netw.spawn(make_arena)
        add_child(arena)
        for player: NetwPlayer in Netw.session(self).players:
            arena.add_child(Netw.spawn_player(player, make_car))

|void| **action**\ (\ method\: :godot:`Callable`, tick\: :godot:`int`, ...\ ) |vararg| |static| :ref:`🔗<class_Netw_method_action>`

Asks the server to run ``method``, an action declared with :ref:`configure_action()<class_Netw_method_configure_action>`. ``tick`` is the tick the player acted on, and the arguments after it are passed to ``method`` and to the :ref:`NetwActionConfig.predict()<class_NetwActionConfig_method_predict>` handler. Only the peer that controls the :ref:`NetwEntity<class_NetwEntity>` sends a request.

::

    func _network_process(delta: float, tick: int, is_fresh: bool) -> void:
        if is_fresh and bombing:
            Netw.action(place_bomb, tick, position)

.. _class_Netw_method_despawn:

:godot:`Error <@GlobalScope#enum_@globalscope_Error>` **despawn**\ (\ node\: :godot:`Node`, opts\: :ref:`NetwDespawnOpts<class_NetwDespawnOpts>` = null\ ) |static| :ref:`🔗<class_Netw_method_despawn>`

.. _class_Netw_method_reparent:

.. rst-class:: classref-method

:ref:`NetwPromise<class_NetwPromise>` **reparent**\ (\ node\: :godot:`Node`, new_parent\: :godot:`Node`\ ) |static| :ref:`🔗<class_Netw_method_reparent>`

Moves ``node`` under ``new_parent`` like :godot:`Node.reparent() <Node#class_Node_method_reparent>`. The promise resolves once the server has moved it. Other peers move it after. Every peer keeps the node's global transform across the move.

::

    await Netw.reparent(avatar, level2.get_node(^"Players")).wait()

\ A level keeps its :ref:`NetwScene<class_NetwScene>`, its viewers and every :ref:`NetwPlayer.scene<class_NetwPlayer_property_scene>` when it moves. For a level made with :ref:`NetwSceneConfig.isolated()<class_NetwSceneConfig_method_isolated>`, pass the node :ref:`spawn()<class_Netw_method_spawn>` returned or the level's root, and the node :ref:`spawn()<class_Netw_method_spawn>` returned moves.

\ :godot:`Area3D` and :godot:`Area2D` do not fire enter and exit signals during the move (`Godot issue 14578 <https://github.com/godotengine/godot/issues/14578>`__). An overlap that really changed during the move is reported after it with the body and area enter and exit signals, without the shape signals.

The promise fails with :godot:`@GlobalScope.ERR_DOES_NOT_EXIST <@GlobalScope#class_@GlobalScope_constant_ERR_DOES_NOT_EXIST>` when ``node`` has no entity, and :godot:`@GlobalScope.ERR_UNAVAILABLE <@GlobalScope#class_@GlobalScope_constant_ERR_UNAVAILABLE>` outside a session.

A client can call it when its player is the :ref:`NetwEntity.controller<class_NetwEntity_property_controller>` and :ref:`NetwEntity.lifecycle<class_NetwEntity_property_lifecycle>` is :ref:`NetwEntity.LIFECYCLE_CONTROLLER<class_NetwEntity_constant_LIFECYCLE_CONTROLLER>`. The node moves on that client at once, and moves back if the server refuses.

.. _class_Netw_method_request_all:

.. rst-class:: classref-method

:ref:`NetwGroupPromise<class_NetwGroupPromise>` **request_all**\ (\ method\: :godot:`Callable`, ...\ ) |vararg| |static| :ref:`🔗<class_Netw_method_request_all>`

Calls ``method`` on every peer that can see the node, and returns a :ref:`NetwGroupPromise<class_NetwGroupPromise>` with each return value. The promise fails at once when the node is not part of a spawned :ref:`NetwEntity<class_NetwEntity>`.

This peer is asked too when the method is ``call_local``, set through :godot:`@GDScript.@rpc <@GDScript#class_@GDScript_annotation_@rpc>` or :ref:`NetwMemberConfig.call_local()<class_NetwMemberConfig_method_call_local>`. The method may ``await`` for 5 seconds, and :ref:`NetwMemberConfig.timeout()<class_NetwMemberConfig_method_timeout>` sets a longer deadline.


.. tabs::

 .. code-tab:: gdscript

    extends Node

    const MATCH := "res://match.tscn"

    var warm: PackedScene

    func _init() -> void:
        Netw.configure_entity(self)
        Netw.configure_rpc(preload_level).timeout(60.0)
        Netw.configure_spawn(make_match)
        Netw.configure_spawn(make_player)

    func start_match() -> void:
        var loads := Netw.request_all(preload_level, MATCH)
        await loads.wait()
        if loads.is_failed or false in loads.results.values():
            return
        var arena: Node = Netw.spawn(make_match)
        add_child(arena)
        for player: NetwPlayer in Netw.session(self).players:
            arena.add_child(Netw.spawn_player(player, make_player))

    func make_match() -> Node:
        return warm.instantiate()

    @rpc("authority")
    func preload_level(path: String) -> bool:
        ResourceLoader.load_threaded_request(path)
        while ResourceLoader.load_threaded_get_status(path) \
                == ResourceLoader.THREAD_LOAD_IN_PROGRESS:
            await get_tree().process_frame
        warm = ResourceLoader.load_threaded_get(path)
        return warm != null

 .. code-tab:: csharp

    public partial class SceneManager : Node
    {
        const string Match = "res://match.tscn";

        PackedScene warm;

        public SceneManager()
        {
            Netw.ConfigureEntity(this);
            Netw.ConfigureRpc(this, MethodName.PreloadLevel).Timeout(60.0);
            Netw.ConfigureSpawn(this, MethodName.MakeMatch);
            Netw.ConfigureSpawn(this, MethodName.MakePlayer);
        }

        public async void StartMatch()
        {
            NetwGroupPromise loads = await Netw.RequestAll(this, MethodName.PreloadLevel, Match);
            if (loads.IsFailed || loads.Results.Values.Any(loaded => !loaded.AsBool()))
                return;
            Node arena = Netw.Spawn(this, MethodName.MakeMatch);
            AddChild(arena);
            foreach (NetwPlayer player in Netw.Session(this).Players)
                arena.AddChild(Netw.SpawnPlayer(player, this, MethodName.MakePlayer));
        }

        public Node MakeMatch() => warm.Instantiate();

        public Node MakePlayer() => new Node();

        public Variant PreloadLevel(string path) => NetwPromise.FromTask(Preload(path));

        async Task<bool> Preload(string path)
        {
            ResourceLoader.LoadThreadedRequest(path);
            while (ResourceLoader.LoadThreadedGetStatus(path)
                    == ResourceLoader.ThreadLoadStatus.InProgress)
                await ToSignal(GetTree(), SceneTree.SignalName.ProcessFrame);
            warm = ResourceLoader.LoadThreadedGet(path) as PackedScene;
            return warm != null;
        }
    }

.. _class_Netw_method_spawn:

.. rst-class:: classref-method

:godot:`Node` **spawn**\ (\ method\: :godot:`Callable`, ...\ ) |vararg| |static| :ref:`🔗<class_Netw_method_spawn>`

Calls ``method`` with the arguments after it on every peer, and returns the node it made here. Add the node before the next tick, under a node every peer has.

::

    muzzle.add_child(Netw.spawn(make_bullet, direction))

\ Register ``method`` with :ref:`configure_spawn()<class_Netw_method_configure_spawn>` first. A player who joins later calls ``method`` too, with the same arguments.

The node outlives every player. :ref:`spawn_player()<class_Netw_method_spawn_player>` makes one that is despawned with its player.

A client can call it when the node sets :ref:`NetwEntity.lifecycle<class_NetwEntity_property_lifecycle>` to :ref:`NetwEntity.LIFECYCLE_CONTROLLER<class_NetwEntity_constant_LIFECYCLE_CONTROLLER>`. That client's player becomes its :ref:`NetwEntity.controller<class_NetwEntity_property_controller>`. The client sees it at once and loses it if the server refuses.

\ ``method`` returns without waiting. Use :ref:`spawn_async()<class_Netw_method_spawn_async>` when it awaits.

.. _class_Netw_method_spawn_player:

.. rst-class:: classref-method

:godot:`Node` **spawn_player**\ (\ player\: :ref:`NetwPlayer<class_NetwPlayer>`, method\: :godot:`Callable`, ...\ ) |vararg| |static| :ref:`🔗<class_Netw_method_spawn_player>`

Like :ref:`spawn()<class_Netw_method_spawn>`, and writes :ref:`NetwEntity.player<class_NetwEntity_property_player>` on the node ``method`` returns. The two lines below spawn the same entity.

::

    players.add_child(Netw.spawn_player(player, make_avatar))
    players.add_child(Netw.spawn(make_avatar_of, player.peer_id))

    func make_avatar_of(peer_id: int) -> Node:
        var avatar := make_avatar()
        var who := Netw.session(self).player_of(peer_id)
        NetwEntity.of(avatar).player = who
        return avatar

\ Returns ``null`` and spawns nothing when the session does not hold ``player``, and raises an error unless that player left the session. The node keeps the name ``method`` gave it, and :ref:`NetwEntity.name<class_NetwEntity_property_name>` is the player's :ref:`NetwPlayer.username<class_NetwPlayer_property_username>`. The node is despawned when ``player`` leaves. With :ref:`NetwPersistenceConfig.load_on_spawn()<class_NetwPersistenceConfig_method_load_on_spawn>`, other peers receive it once its save is loaded. When the spawn is refused, ``player`` stays in the session and its client prints a warning that names ``method``.
